# RFT-SiM for :robot:s
***built on Python 3.12.10 and MuJoCo 3.3.7***
# [RFT_simulation_crabwalking.ipynb](RFT_simulation_crabwalking.ipynb)
- this runs an example :crab: robot simulation in the RFT-MuJoCo pipeline.
  - outputs: robot position over time, video of simulation

# [sim_fxn_lib.py](sim_fxn_lib.py)
- houses helper functions and RFT force code

# [Rigid_crabwalking](Rigid_crabwalking.ipynb) 
- example robot simulation without sand ground

# asset
- contains meshes and textures for model
